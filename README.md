\# UCU Hostel Borrowing App



\## Project Overview

A student borrowing platform for Uganda Christian University (UCU) hostel residents.



The platform will allow students to list items they are willing to lend and allow other students to request to borrow those items.



\## Main Objectives

\- Allow students to list available items.

\- Allow students to request items.

\- Track borrowing and return processes.

\- Display the current status of each item.

\- Make borrowing between hostel residents easier and more organized.
